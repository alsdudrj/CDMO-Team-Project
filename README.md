# 팀 단위 CDMO 프로젝트

## 소개
학원에서 팀으로 협업하여 제작중인 CDMO 프로젝트 입니다. (제작중..)

## 인원수
- 3명

## 주요 기능
- 회원가입 / 로그인
- 공정 레시피 생성
- 레시피에 따른 공정 시뮬레이션 생성
- 일탈감지 시뮬레이션 생성
- AuditLog 관리

## 기술 스택
### Frontend
- React

### Backend
- Spring Boot

## 프로젝트 구조
Frontend: SPA 구조  
Backend: REST API 기반
