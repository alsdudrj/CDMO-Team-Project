# 팀 단위 CDMO 프로젝트

## 소개
학원에서 팀으로 협업하여 제작중인 CDMO 프로젝트 입니다. (제작중..)

CDMO(Contract Development and Manufacturing Organization)란
의약품 위탁 개발 및 생산기관을 뜻하며, 
제약·바이오 기업의 의약품 개발, 임상시험 서비스, 제조 공정 개발부터 상업 생산까지 전 과정을 통합적으로 제공하는 전문 서비스입니다.

## 프로젝트 참여 인원수
- 3명
  
### 협업 방식
- GitHub Flow

## 주요 기능
- 회원가입 / 로그인
- 공정 레시피 생성
- 레시피에 따른 공정 시뮬레이션 생성
- 실시간 공정 시뮬레이션 데이터 확인 및 진행도 확인
- 일탈감지 시뮬레이션 생성
- AuditLog 관리

## 기술 스택
### Frontend
- React

### Backend
- Spring Boot

## 프로젝트 구조
Frontend: SPA 구조  
Backend: REST API 기반
